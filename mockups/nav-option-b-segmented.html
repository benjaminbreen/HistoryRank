Option B — Centered Segmented Pill

Design Approach

Key idea: All primary navigation lives in a single centered segmented control (pill shape), inspired by Apple's design language and modern SaaS tools. The logo anchors the left edge, secondary meta-links (About, Method) are demoted to the right side in a lighter weight.

Improvements over current: Removes the "Explore" dropdown entirely — every page is one click away. The centered position draws the eye naturally. The active state is a clean white raised segment against the light gray trough. The dark square logo mark feels more modern than the current circle. The bottom accent line is a subtle nod to the gold/blue warm-cool palette.

Trade-off: Uses more horizontal space, so on smaller desktop screens (<1100px) you'd need to either abbreviate labels or switch to icons-only. But for a data-dense tool like HistoryRank, full-width usage is expected.
